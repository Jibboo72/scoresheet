    How to read this

    Every 2025-26 game was projected using only information available before puck drop. The big number compares the model against a plain season average. Positive means sharper.

    Average miss is how far the model’s odds sat from what actually happened. Under 2 points is solid for props. No sportsbook prices are in this test yet, so this shows accuracy, not profit.
